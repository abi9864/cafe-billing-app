Section 1

Project Overview

Raja's Cafe Billing App is a full-stack, multi-location Point-of-Sale and business management system designed for cafes and restaurants. It handles the complete order-to-payment lifecycle, inventory tracking, staff management, loyalty programs, and business analytics — all from a single web interface.

✅

Current Status: Fully operational. Backend API running on port 5000, React frontend on port 3000, PostgreSQL database initialized with Raja's Cafe demo data.

Key Features

🛒 Point of Sale

  • Fast menu browsing with category filters
  • Cart management with variants
  • Dine-in / Takeaway / Delivery order types
  • Promo code discounts
  • Multi-method payments (Cash/Card/Mobile)
  • Change calculation for cash
  • Printable receipts

📦 Operations

  • Live order status tracking
  • Kitchen display integration
  • Inventory with reorder alerts
  • Shift open/close management
  • Supplier management
  • Loyalty points program
  • Audit logging

📊 Analytics

  • Real-time dashboard KPIs
  • Revenue charts (daily/weekly/monthly)
  • Top-selling item reports
  • Payment method breakdown
  • Tax/GST reports

🏢 Administration

  • Multi-location (branch) support
  • 5-tier role-based access control
  • User account management
  • Menu & category CRUD with images
  • Tax rates and discount configuration

Request Flow

  1. 1
    User Action User interacts with the React UI (e.g. clicks "Add to Cart", "Place Order").
  2. 2
    API Request Axios sends an HTTP request to the Express backend with a JWT Bearer token in the Authorization header.
  3. 3
    Authentication & Authorization The authenticate middleware verifies the JWT. The authorize(...roles) middleware checks if the user's role is permitted for that endpoint.
  4. 4
    Database Query The route handler queries PostgreSQL via the connection pool and returns JSON.
  5. 5
    UI Update TanStack Query receives the response, updates the cache, and React re-renders the relevant components.

Option A — Local Development (Recommended)

Step 1 — Clone the repository

git clone https://github.com/abi9864/cafe-billing-app.git
cd cafe-billing-app
git checkout full-app-setup

Step 2 — Install dependencies

# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install

Step 3 — Configure environment

Create backend/.env.local (copy from .env.example and edit):

PORT=5000
NODE_ENV=development
DB_HOST=localhost
DB_PORT=5432
DB_NAME=cafe_billing
DB_USER=postgres
DB_PASSWORD=<your_postgres_password>
JWT_SECRET=your_super_secret_jwt_key_change_in_production_min_32_chars
JWT_EXPIRES_IN=24h
CORS_ORIGIN=http://localhost:3000
UPLOAD_DIR=uploads/

Create frontend/.env.local:

VITE_API_URL=http://localhost:5000

Step 4 — Set up the database

# Create database
psql -U postgres -c "CREATE DATABASE cafe_billing;"

# Run schema (creates 20 tables)
psql -U postgres -d cafe_billing -f database/schema.sql

# Load seed data (demo data for Raja's Cafe)
psql -U postgres -d cafe_billing -f database/seeds.sql

# Create uploads folder
mkdir -p backend/uploads/menu

Step 5 — Start both servers

# Terminal 1 — Backend (auto-reload with nodemon)
cd backend
npm run dev
# → Server running on port 5000

# Terminal 2 — Frontend (Vite dev server)
cd frontend
npm run dev
# → Local: http://localhost:3000
🎉

Open http://localhost:3000 and log in with admin@cafe.com / password123

Option B — Docker (Production)

docker-compose up -d

This starts three containers: postgres (port 5432), backend (port 5000), and frontend served via Nginx (port 3000). After the first start, run schema and seeds manually against the postgres container.

⚠️

Change JWT_SECRET and the PostgreSQL password in docker-compose.yml before deploying to production.

8.2 POS Interface Route: /pos

  1. 1
    Browse the Menu Use the category tabs at the top to filter items, or type in the search box. Each card shows the name, price, prep time, and a 🌱 icon for vegetarian items.
  2. 2
    Add Items to Cart Click any menu item. If it has variants (e.g. Regular / Large), a picker modal appears — select a variant then click Add. Items are added to the right-side cart panel.
  3. 3
    Set Order Type & Details Click Dine-In, Takeaway, or Delivery. For Dine-In enter the table number. Optionally add customer name, phone, and special instructions.
  4. 4
    Apply Discount (Optional) Enter a promo code (e.g. WELCOME10) and click Apply. Valid codes show the discount amount in the totals.
  5. 5
    Review Totals The cart footer shows: Subtotal → Discount → GST (5%) → Total.
  6. 6
    Process Payment Click the orange Charge ₹XXX button. In the Payment Modal:
      • Cash: Enter amount tendered → change is shown automatically
      • Card / Mobile: Select method → confirm
      • Split: Enter amounts for multiple methods
  7. 7
    Print Receipt After payment, the Receipt Modal opens automatically. Click Print to send to printer. The cart clears and is ready for the next order.

User Manual — Operations

8.3 Orders Management Route: /orders

View and manage all orders. Auto-refreshes every 30 seconds. Use the status filter bar to show only a specific stage, or search by order number / customer name.

StatusMeaningNext Status ActionsPayment Button
PendingOrder placed, not yet confirmed✅ Confirm  |  ❌ Cancel₹ Collect Payment
ConfirmedOrder acknowledged, queued for kitchen🍳 Preparing  |  ❌ Cancel₹ Collect Payment
PreparingKitchen is actively working on it✅ Ready  |  ❌ Cancel₹ Collect Payment
ReadyFood/drink ready for pickup or serving✅ Complete  |  ❌ Cancel₹ Collect Payment
CompletedDelivered to customer—₹ Collect Payment (if unpaid)
CancelledOrder was cancelled——
💡

Collect Payment (₹ button): Appears on every unpaid, non-cancelled order — in the table row and inside the Order Detail Modal. Opens a payment modal to select Cash / Card / Mobile, enter cash tendered (with auto change calculation), and confirm. On success the order is marked is_paid = true, a payment record and receipt number are created, shift totals are updated, and the Dashboard KPIs refresh immediately.

Click any row to open the Order Detail Modal — shows all line items, quantities, variant names, special instructions, discount, tax breakdown, order total, payment status, and all available action buttons (status transitions + Collect Payment).

8.4 Dashboard Route: /admin Admin / Manager

  • KPI Cards: Today's Revenue, This Week's Revenue, Active Orders count, Low Stock Alerts
  • Revenue Chart: Bar chart for the last 7 days
  • Top Items: Ranked list of best-selling items this week with quantity sold
  • Refreshes automatically every 30 seconds; also updates instantly when any order status is changed from the Orders page

8.5 Menu Management Route: /menu Admin / Manager

Items Tab

  • Grid view of all menu items with images
  • Click + Add Item to open the form modal
  • Fill in: Name, Category, Base Price, Description, Prep Time, Vegetarian flag
  • Upload a product image (PNG/JPG, max 5 MB)
  • Add size variants (e.g. Regular = ₹0, Large = +₹30)
  • Click the edit ✏️ icon on any card to modify
  • Toggle availability with the active switch

Categories Tab

  • List of all categories for the current location
  • Add new category with name and description
  • Reorder using display_order field
  • Delete empty categories

8.6 Inventory Route: /inventory Admin / Manager

  • Table view of all inventory items; rows highlighted in red when stock is below the reorder level
  • Use the "Show Low Stock Only" toggle to filter critical items
  • Adjust Stock button → opens modal to log: Stock In, Stock Out, or Adjustment with a reason note
  • View History button → shows complete transaction log for an item
  • Add Item → create a new inventory item with unit of measure, reorder level, and reorder quantity
